# 🌦️ تطبيق أحوال الطقس - Weather App

موقع احترافي يعرض حالة الطقس الحالية والتوقعات باستخدام:
- **Frontend:** HTML + CSS + JavaScript
- **Backend:** Node.js + Express
- **API:** Open-Meteo (مجاني بالكامل - لا يحتاج API Key)

## ✨ المميزات
- 🔍 بحث عن أي مدينة في العالم (بالعربية)
- 🌡️ الطقس الحالي: درجة الحرارة، الرطوبة، الرياح، الضغط، السحب، الهطول
- 📈 توقعات 24 ساعة (ساعة بساعة)
- 🗓️ توقعات 7 أيام (مع شروق/غروب الشمس واحتمال المطر)
- 📱 تصميم متجاوب بالكامل (Glassmorphism + حركات)

## 🚀 التشغيل

```bash
# 1. ثبّت المكتبات
npm install

# 2. شغّل السيرفر
npm start
# أو للتطوير مع إعادة التشغيل التلقائي:
npm run dev
```

ثم افتح المتصفح على: `http://localhost:3000`

## 📁 هيكل المشروع

```
weather-app/
├── server.js          ← السيرفر + ربط API الطقس
├── package.json
└── public/
    ├── index.html     ← الصفحة الرئيسية
    ├── style.css      ← التصميم الاحترافي
    └── script.js      ← منطق الواجهة وجلب البيانات
```

## 🔌 الـ API Endpoints

| المسار | الوصف |
|---|---|
| `GET /api/search?q=الرياض` | البحث عن مدينة |
| `GET /api/weather?lat=..&lon=..` | الطقس الحالي + التوقعات |

> ملاحظة: الـ Frontend لا يتصل بـ Open-Meteo مباشرة — يمر عبر السيرفر (Node.js) وهذا أفضل للأمان وتنظيم الكود.
